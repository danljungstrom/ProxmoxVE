## Findings (40 kept)

### Stability — update path (5)
- **A1 (Medium, Codex-modified from High)** ct/happier.sh:125 — `relay host install` unguarded
  under the ERR trap; a failure aborts the update after CLI self-update but before the daemon
  restart, leaving the daemon on the old CLI. The 2026-07-03 matrix documented this exact vendor
  command failing (stable channel; restart-looping unit). Fix like the guarded self-update.
- **A2 (Medium)** ct/happier.sh:120-126 — update unconditionally reinstalls + restarts the relay
  even when the installer disabled it (AUTOSTART=0 → `systemctl disable --now`,
  install/happier-install.sh:757-763). No `is-enabled` probe.
- **A3 (Medium)** ct/happier.sh:121 vs install/happier-install.sh:700-736 — update reinstalls the
  relay with a reduced arg set: none of the 5 install-time `--env` values, no `--auto-update-at`,
  no capability probe, bare invocation. Install-side comment says reinstall "needs the exact same
  argument set". Drift factual; whether the vendor CLI resets persisted env is unproven.
- **A4 (Medium)** install/happier-install.sh:838-839 — ensure_relay_host_installed recovery
  reinstall is `|| true` with no post-check; install can print "complete" with no relay unit.
- **A5 (Low)** install/happier-install.sh:709 — `--help | grep -q` capability probe under
  pipefail: CLI non-zero exit or SIGPIPE silently disables the user's auto-update opt-in.

### UI bundle integrity/perf (5)
- **A6 (Low)** misc/happier-common.func:411 — `ln -sfn` is unlink+create, not atomic; comment
  advertises an atomic swap. Use `ln -s` to temp + `mv -T`.
- **A7 (Low)** misc/happier-common.func:401 — refresh mode runs with errexit suspended
  (if-condition call site); the unguarded move-aside `mv` can fail and the next `mv` nests the
  staging dir inside the live version dir, reporting success with stale content. Stale
  `.old.$$`/`.tmp.$$` dirs are never swept.
- **A8 (Low)** misc/happier-common.func:230-237 — tag-fallback loop shares one stdout redirect;
  a truncated attempt corrupts the JSON for the next, defeating the designed fallback.
- **B3 (Low)** misc/happier-common.func:335-364 — no rollback protection: an older validly-signed
  checksums+archive pair replays cleanly (TUF-style downgrade; needs release-asset control;
  static UI assets only). Fix pairs with P1.
- **P1 (Medium)** misc/happier-common.func:340-411 — refresh re-downloads/verifies/extracts the
  full archive even when the installed version is already current (readable from the `current`
  symlink). Runs on every update incl. the daily timer; ~5-30 s+ waste in the common no-op case.
