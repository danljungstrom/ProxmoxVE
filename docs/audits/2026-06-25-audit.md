## Summary
Follow-up to the 2026-06-24 audit, whose 21 findings were verified this run as correctly fixed (security/stability/modernity all returned **clean** — the Ctrl+C trap, `set_env_kv` escaping, os-release parse, tailscale keyring, atomic UI swap, and service-name fixes all hold; Node 24 / Debian 13 / tailscale keyring confirmed current via live sources). Two themes remain. **(1) Duplication:** `install/happier-install.sh` and `ct/happier.sh` still copy-paste ~7 helper groups — including byte-identical **GitHub-token secret-handling** and **minisign/sha256 supply-chain verify** logic that must be patched in lockstep (the verify copy has *already drifted* on pubkey caching + warning condition). These collapse into one `misc/happier-common.func` extraction, best done during the upstream re-apply below. **(2) One real functional bug:** in `from_source` mode `HAPPIER_PVE_SERVER_PORT` only rewrites advertised URLs — the server still binds 3005 → unreachable state. Plus doc-scoping and a missing CI lint gate. **Headline (separate work):** the fork is **1910 commits / ~4 months behind** upstream `community-scripts/ProxmoxVE`; the recommended sync path is reset-to-upstream + re-apply (3 files + 2 small patches), during which the dedup epic is naturally resolved — see the dedicated section.

**Recommended strategy — (c) reset fork content to `upstream/main` + re-apply the happier additions as a clean patch set.**
Not (a) merge (giant conflicted build.func + reintroduced `frontend/` delete/modify conflict) and not (b) rebase (33 WIP commits × 80 build.func commits = same conflict 33×, little history value). The durable surface is just **3 new files + 2 small patches**, almost entirely orthogonal to upstream churn.
Steps: (1) new branch from `upstream/main`, archive current branch; (2) restore `ct/happier.sh` + `install/happier-install.sh` verbatim **(ideally via the new `misc/happier-common.func` — resolves the dedup epic in the same pass)**; decide happier.json's fate; (3) re-apply build.func override onto upstream's current structure (all fetch sites); (4) re-apply core.func apt hardening; (5) verify `ct` override wiring still aligns; (6) **LXC test gate** end-to-end (fetches from `happier-dev/ProxmoxVE`, installer runs, apt cleanup doesn't hang, daemon-auth works) before any push; commit via `/commit`.
