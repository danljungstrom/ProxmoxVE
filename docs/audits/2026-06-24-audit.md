# Repo audit — happier-dev/ProxmoxVE (Happier helper scripts) — 2026-06-24

Tier: standard · Stack: bash (Proxmox VE community-scripts) · Web app: no
Scope: `install/happier-install.sh`, `ct/happier.sh`, `frontend/public/json/happier.json`
Dimensions run: security, stability, modernity, consistency · Findings: 21 (Critical 0 / High 5 / Medium 7 / Low 9)
Verification: Claude-only (High findings + the auth-code finding adversarially self-verified against `misc/error_handler.func`). Codex alignment pass NOT run — findings carry no Codex sign-off.

## Summary
The colleague's refactor is generally solid bash (modern idioms, careful tailscale exit-code handling, correct GitHub-token-via-`--config` and tailscale-authkey hygiene, real minisign+sha256 supply-chain verification — ahead of house style). The biggest real risks are two **High** functional bugs: (1) the just-added interactive daemon-auth claims Ctrl+C "skips," but the framework's global `INT` trap (`on_interrupt → exit 130`) means Ctrl+C aborts the whole installer and skips all post-install guidance; (2) `ct/happier.sh`'s `update_script` restarts a service name (`happier-daemon.*.service`) that the installer never creates (`happier-server${suffix}`), so updates silently restart nothing. Supply-chain `curl|bash`/unpinned-`main` findings are real but largely inherent to the community-scripts model. A recurring theme is **drift between the two install paths and between `ct` and `install`** (duplicated helpers that have diverged): service-restart idiom, CLI resolution, release-repo var name, UI-bundle logic, post-install step numbering.

## Findings by dimension

### security
- **[High] Installer bootstrap piped from network into bash, no integrity check** — `install/happier-install.sh:545`
  - Evidence: `curl -fsSL "https://happier.dev/install" | $STD bash -s -- --channel "${HAPPIER_CHANNEL}"` runs as root with no checksum/signature, despite minisign being a hard dep used elsewhere in the same file.
  - Recommendation: download to temp, verify pinned minisign sig / sha256, then execute; or pin an immutable URL + verify a published checksum. · Effort: M · Confidence: 0.9
  - Note: inherent to the community-scripts model to a degree, but this pipes the happier-owned installer specifically.
- **[High] `build.func` sourced+executed from mutable `main` ref, no integrity check** — `ct/happier.sh:6`
  - Evidence: `BUILD_FUNC="$(curl -fsSL "https://raw.githubusercontent.com/${INSTALLER_REPO}/${INSTALLER_REF}/misc/build.func")"; source /dev/stdin <<<"${BUILD_FUNC}"` with `INSTALLER_REF` defaulting to `main` (line 3). Host-side root code from an unpinned remote.
  - Recommendation: pin `INSTALLER_REF` to a tag/SHA + verify checksum before sourcing. · Effort: M · Confidence: 0.85
  - Note: every community-scripts `ct/*.sh` does this; accepted-risk for the ecosystem.
- **[High] Auto-generated `/usr/bin/update` re-runs unpinned remote script via `curl|bash` as root** — `install/happier-install.sh:888` (dup at `:1387`)
  - Evidence: heredoc writes `curl -fsSL https://raw.githubusercontent.com/happier-dev/ProxmoxVE/main/ct/happier.sh | bash` — fetches `main`, no verify.
  - Recommendation: pin to a release tag/SHA + verify, or call the channel-aware CLI self-update (already minisign-verifies). · Effort: M · Confidence: 0.85
- **[Medium] `from_source` runs unpinned npm package via `npx --yes` (`@latest`/`@next`)** — `install/happier-install.sh:928`
  - Evidence: `npx --yes -p "${STACK_PACKAGE}" hstack setup-from-source ...`; `STACK_PACKAGE` defaults to `@happier-dev/stack@latest`/`@next` — mutable dist-tags, no integrity pin.
  - Recommendation: pin exact version and/or SRI; or verify a signature post-download. · Effort: M · Confidence: 0.8
- **[Medium] minisign verification public key overridable via env** — `install/happier-install.sh:71`
  - Evidence: `MINISIGN_PUBKEY="${HAPPIER_MINISIGN_PUBKEY:-${DEFAULT_MINISIGN_PUBKEY}}"` (also `ct/happier.sh:184`). Verification is fatal, but the trust anchor itself is env-replaceable.
  - Recommendation: treat the pinned pubkey as non-overridable in the production path, or warn loudly when overridden. · Effort: S · Confidence: 0.7
- **[Low] Server env file not chmod-restricted (no `chmod 600`)** — `install/happier-install.sh:964`
  - Evidence: `touch "$STACK_ENV_FILE"; chown happier:happier "$STACK_ENV_FILE"` — chowned but never chmod'd; inherits umask. No secrets today, but no permission floor if tokens land there later.
  - Recommendation: `chmod 600` the file / `700` the dir right after creation (mirror the token temp-config at `:247`). · Effort: S · Confidence: 0.6
  - Cleared (no finding): `happier_github_curl` token handling (mktemp+chmod600+`--config`, rm'd in all paths) and tailscale pre-auth key ("not saved") both verified correct.

### stability
- **[High] Ctrl+C during interactive daemon auth aborts the whole install instead of skipping** — `install/happier-install.sh:709-729` (call sites `:754`, `:1237`)
  - Evidence: helper comment says "Ctrl+C skips and falls back," call is `if timeout 300 sudo -u happier -H "$@" </dev/null; then`. But `catch_errors` installs `trap on_interrupt INT` (`misc/error_handler.func:445`) and `on_interrupt` ends `exit 130` (`:386`). SIGINT hits the whole foreground group → global trap exits the installer; the `if` only catches a non-zero **return** (e.g. timeout's 124), never the signal. An abort here also skips all post-install Next-steps output. **(Bug in the newly-added auth code.)**
  - Recommendation: install a local `trap '...; return 1' INT` around the timeout call (save/restore), or run auth in its own process group and translate 130→skip; and correct the comment/on-screen text. · Effort: M · Confidence: 0.85
- **[Medium] `set_env_kv` sed escaping broken for `&` (and `|`) — corrupts env values** — `install/happier-install.sh:970`
  - Evidence: `escaped="$(printf '%s' "$value" | sed -e 's/[|&]/\\\\&/g')"` then `sed -i "s|^${key}=.*|${key}=${escaped}|"`. The `&` is not escaped as a replacement metachar; a value like `...?x=1&y=2` re-inserts the matched LHS. Reproduced live.
  - Recommendation: `escaped="$(printf '%s' "$value" | sed -e 's/[\\&|]/\\&/g')"` (single-backslash; escape `\`, `&`, and the `|` delimiter). · Effort: S · Confidence: 0.95
- **[Medium] os-release `grep|cut` assignments can trip the ERR trap / build broken apt URL** — `install/happier-install.sh:599-600` (also `:1074-1075`)
  - Evidence: `ID=$(grep "^ID=" /etc/os-release | cut -d"=" -f2)` / `VER=$(grep "^VERSION_CODENAME=" ...)`. Under `set -Ee -o pipefail` a missing line → non-zero pipeline → ERR trap aborts mid-tailscale-setup; empty values silently build a bad apt source.
  - Recommendation: `. /etc/os-release` then `${ID:?}`/`${VERSION_CODENAME:?}` with a clear `msg_error`, or `|| true` + non-empty validation. · Effort: S · Confidence: 0.8
- **[Low] Tailscale keyring `tee` runs unguarded; pipeline failure aborts with no cleanup** — `install/happier-install.sh:1076` (also `:601`)
  - Evidence: `curl -fsSL ".../${VER}.noarmor.gpg" | tee /usr/share/keyrings/tailscale-archive-keyring.gpg >/dev/null` — no `$STD`, no `|| msg_error`; transient failure aborts via ERR trap leaving half-written keyring + `tailscale.list`.
  - Recommendation: capture curl to temp, verify non-empty, then install keyring + source together with a `msg_error` on failure. · Effort: S · Confidence: 0.7
- **[Low] Managed UI-bundle install non-atomic: `rm -rf` of live version dir before copy succeeds** — `install/happier-install.sh:408` (dup `ct/happier.sh:273`)
  - Evidence: `rm -rf "${version_dir}"; mkdir -p ...; cp -a ...; ln -sfn ...`; a cp/tar failure (under ERR trap) leaves the prior-good version destroyed with no rollback.
  - Recommendation: stage into a temp dir, `mv`/`ln -sfn` only after cp succeeds; don't delete the live dir first. · Effort: M · Confidence: 0.65
- **[Low] Background `hstack start` is fire-and-forget; no readiness check before daemon auth** — `install/happier-install.sh:1066`
  - Evidence: `nohup "$HSTACK_BIN" start --restart ... &` (AUTOSTART!=1, from_source), then later `auth login --start-if-needed` can race an unready server; `wait_for_systemd_active` is only used on the systemd path.
  - Recommendation: poll the server port/health briefly before auth, or rely solely on `--start-if-needed`. · Effort: M · Confidence: 0.6

### modernity
- **[Low] Tailscale apt source hardcodes the deb line instead of upstream `.tailscale-keyring.list`** — `install/happier-install.sh:601` (dup `:1076`)
  - Evidence: script composes `echo "deb [signed-by=...] https://pkgs.tailscale.com/stable/${ID} ${VER} main"` by hand. Tailscale's current guidance (verified 2026-06, tailscale.com/docs/install/linux) ships a ready `${VER}.tailscale-keyring.list`. Approach is NOT deprecated (uses `/usr/share/keyrings` + `signed-by`, no `apt-key`) — freshness nit only.
  - Recommendation: fetch the upstream `.tailscale-keyring.list`; factor the duplicated tailscale block into one helper. · Effort: S · Confidence: 0.6

### consistency

  - Recommendation: reuse `channel_relay_service_name` in `update_script` and restart `happier-server${suffix}`, or `${cli_bin} relay host restart --mode system --channel` (matching `install:633`). · Effort: S · Confidence: 0.85

## Epics (proposed)
- **Supply-chain integrity** (security) → curl|bash installer (`:545`), build.func unpinned main (`ct:6`), `/usr/bin/update` unpinned (`:888`), npx `@latest`/`@next` (`:928`), minisign pubkey env-overridable (`:71`).
- **Interactive daemon-auth correctness** (stability) → Ctrl+C aborts whole install (`:709-729`); align wait-for-auth flag across paths (`:1027`); post-install numbering (`:843`/`:1290`).
- **De-duplicate `ct` ↔ `install` drift** (consistency) → service-name mismatch (`ct:316`), restart idiom (`:633`), CLI resolution fallback (`ct:166`), release-repo var (`ct:183`), UI-bundle drift (`ct:227`), dead `channel_config_env_path` (`:152`).
- **ERR-trap / failure-path hardening** (stability) → `set_env_kv` escaping (`:970`), os-release parse (`:599`), tailscale keyring `tee` (`:1076`), non-atomic UI replace (`:408`), env-file chmod (`:964`).
- **Tooling freshness** (modernity) → tailscale `.tailscale-keyring.list` (`:601`).
